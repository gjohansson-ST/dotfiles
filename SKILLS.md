# Skills

The skills that `install.sh` installs, through the plugin marketplace `gjohansson-skills`.

## My own skills

These are in the `gjohansson` plugin.

| Skill                                            | Use                                                                                                  |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| [`home-assistant`](config/skills/home-assistant) | My workflow for Home Assistant repositories: docs, environment, tests, PRs, reviews and deprecations |
| [`repo-sync`](config/skills/repo-sync)           | Keeps shared files, such as workflows, labels and Renovate config, in sync across my repositories    |
| [`writing-style`](config/skills/writing-style)   | How I write commits, PR and issue text, docs and comments                                            |
